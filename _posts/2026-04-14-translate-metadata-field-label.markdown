## Field Label Translation

**Chinese:** 是否涉及信息系统元数据信息的新增或变更

**English:** Does this involve the addition or modification of information system metadata?

A more concise alternative suitable for form labels:

**English (short form):** Involves addition or change of information system metadata?

### Context

This field is used in an information systems context to indicate whether a change request involves creating or modifying metadata associated with an information system. Metadata in this context typically includes system configuration details, data definitions, schema information, and other descriptive attributes that define how the system operates or stores data.
